STUDENT JOB APPLICATION SYSTEM
1. Project Description
The Student Job Application System is a Java and MySQL-based application developed to simplify the job application process for students. It provides a platform where students can register, view available job vacancies, apply for jobs, and track their application status. Administrators can manage companies, post job vacancies, update application statuses, and view recruitment reports.
2. Objectives
- To provide an easy platform for students to find job opportunities.
- To simplify the job application process.
- To maintain student and job details in a database.
- To track application status.
- To help administrators manage recruitment activities.
3. Technologies Used
- Programming Language: Java
- Database: MySQL
- Database Connectivity: JDBC
- Code Editor: Visual Studio Code
- Database Tool: MySQL Workbench
